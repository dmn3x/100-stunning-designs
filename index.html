HTML Designsan open experiment · same prompt · different hands

Two AI models received the same instruction: create 100 HTML files. Look stunning. Zero repetition. Go full creative mode. No libraries. No frameworks. No code generators. Each file is hand-written, self-contained, and opens in any browser.

The tests below are not viral demos — they are stamina tests. They ask whether a model can hold its craft across a hundred designs without collapsing into a single aesthetic, and whether the hundredth page is still its own.

Five things we look for

  1. Creative range

    Can the model span brutalist grids, soft glass, psychedelic canvas, 3D geometry, and quiet monochrome — without ever reusing the same hero the day before?

  2. Technical depth

    Canvas 2D, SVG, CSS animations, transform 3D, vanilla physics. Real interactions, not decorative hovers.

  3. Design taste

    Colour harmony, hierarchy, typography, restraint — the questions most AI still gets wrong.

  4. Zero-dependency discipline

    Does each file work as a single .html open from disk? No fonts, no CDNs, no libraries.

  5. Stamina

    Does quality hold across all hundred? Or does the last page look like a model running on fumes?

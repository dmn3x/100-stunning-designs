# MiniMax M3 — 100 Standalone HTML Designs

## Scope
- Create exactly 100 new self-contained HTML files under `MiniMax M3/`.
- Add `MiniMax M3/index.html` as an editorial gallery / navigation hub.
- Update the root README model table and browsing instructions without changing existing Deepseek files.
- Every design must work when opened directly from disk, without network dependencies, frameworks, images, fonts, or build steps.
- No generator script, shared template, external CSS, or external JavaScript.

## Quality bar
- Every file has its own visual language, layout rhythm, typography treatment, palette, interaction model, and motion system.
- Do not merely recolor or rename a common hero/card template.
- Use semantic HTML, responsive behavior, keyboard-visible focus, reduced-motion handling, and meaningful document titles.
- Prefer canvas/SVG/CSS/vanilla JS where it creates a genuinely distinct experience.
- Avoid placeholder copy and generic SaaS sections.

## Verification checklist
1. Count exactly 100 design HTML files plus `index.html` in `MiniMax M3/`.
2. Check every document has `<!doctype html>`, viewport meta, title, inline style, and no remote URLs.
3. Confirm no two files are byte-identical and each has substantial unique markup/style/script.
4. Open the gallery locally and inspect representative first/middle/last designs at desktop and narrow viewport.
5. Verify `.gitignore` covers common secrets and build artifacts.
6. Commit and push the completed work to the configured GitHub remote.

# 🎨 100 Stunning HTML Designs — An Experiment with Deepseek V4 Pro

**Can an AI model generate 100 completely unique, visually stunning HTML files without repeating itself?**

That was the question. This repo is the answer.

---

## The Experiment

I gave **Deepseek V4 Pro** a single prompt:

> *"Create 100 HTML files. Rules: look stunning, zero repetitive designs, go full creative mode."*

No templates. No libraries. No CSS frameworks. Just raw HTML, CSS, and vanilla JavaScript — each file entirely self-contained.

The model was asked to produce one design at a time, never repeating a concept, spanning every style it could imagine: canvas animations, UI components, 3D effects, creative layouts, interactive toys, and pure visual art.

---

| # | Category | Highlights |
|---|----------|-----------|
| 🌌 | **Canvas Animations** | Particle constellation, kaleidoscope, galaxy spiral, DNA helix, lava lamp, matrix rain, confetti, wormhole |
| 🎨 | **UI Components** | Glassmorphism cards, dark dashboard, command palette, OTP input, kanban board, live chat, tooltips |

**Every single file is different.** No two pages use the same technique, layout, or visual identity.

---

## The Verdict

Deepseek V4 Pro demonstrated:

- ✅ **Creative range** — from brutalist grids to soft glassmorphism to psychedelic canvas art
- ✅ **Technical depth** — Canvas 2D API, CSS animations, 3D transforms, SVG morphing, vanilla JS physics
- ✅ **Design taste** — color harmony, spacing, typography choices across all 100 files
- ✅ **Zero-dependency discipline** — every file works standalone in any browser
- ✅ **Stamina** — maintained quality and variety across all 100 designs without fatigue

**Score: genuinely impressive.** The model showed both creative breadth (100 distinct concepts) and technical depth (correct, working code) throughout.

# 🎨 100 Stunning HTML Designs — AI Model Showdown

**Can AI models generate 100 completely unique, visually stunning HTML files — zero repetition, full creative mode?**

This repo is a living experiment. Each model gets the same prompt, and their results live side-by-side so you can compare them directly.

---

## The Prompt

Every model receives the same instruction:

> *"Create 100 HTML files. Rules: look stunning, zero repetitive designs, go full creative mode."*

No templates. No libraries. No CSS frameworks. Just raw HTML, CSS, and vanilla JavaScript — each file entirely self-contained. One design at a time.

## What We're Measuring

- **Creative range** — can the model span brutalist grids, soft glassmorphism, psychedelic canvas art, 3D geometry?
- **Technical depth** — Canvas 2D API, CSS animations, 3D transforms, SVG, vanilla JS physics?
- **Design taste** — color harmony, spacing, typography, visual hierarchy?
- **Zero-dependency discipline** — does every file work standalone?
- **Stamina** — does quality hold across all 100 designs without fatigue or repetition?
